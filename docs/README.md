# May UI documentation

Apple's design language as a React library — iOS/macOS shapes, real spring
physics, a token layer you can theme, and no runtime dependencies beyond React.

## Guides

- **[Getting started](getting-started.md)** — install, the provider, your first
  component, and styling your own markup.
- **[Theming](theming.md)** — the token layers, light/dark, scoped themes, and
  the tint/primary split.
- **[Motion](motion.md)** — the generated `linear()` springs, the sliding-thumb
  system, and how exits stay mounted.
- **[Components](components.md)** — the three families and where each shape lives.

## See it running

- **[Unified website](https://adit-firdaus.github.io/may-ui/)** — docs,
  interactive component catalog, provider playground, and composed patterns.
- **[Storybook](https://adit-firdaus.github.io/may-ui/storybook/)** — every
  component with its props and states. This is the per-component reference.
